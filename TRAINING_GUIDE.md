### Module 2: Finding a Patient (5 minutes)

**How to search:**
1. Click "Patients" in sidebar
2. Type in the search box:
   - Patient name
   - UHID number
   - Phone number
3. Results appear instantly as you type

**Practice:**
- Search for an existing patient
- Click on their name to open their record

**Pro Tip:** Search works offline! All data is on your device.

---

### Module 3: Patient Details (10 minutes)

**What you'll see when you open a patient:**

1. **Patient Info Tab:**
   - Name, age, gender, contact
   - Medical history
   - Past visits

2. **Vitals Tab:**
   - BP, Pulse, Temperature, SpO2
   - Weight, Height, BMI
   - History graph

3. **Prescriptions Tab:**
   - All past prescriptions
   - View and print old prescriptions

4. **Lab Reports Tab:**
   - All investigations
   - AI analysis of abnormal values
   - Timeline of reports

**Try it:**
1. Open a test patient
2. Click through each tab
3. Notice the AI warnings in lab reports (red/yellow highlights)

---

### Module 4: Writing a Prescription (10 minutes)

**Step-by-Step:**

1. **Open Patient Record:**
   - Search and click patient name
   - Click "Write Prescription" button (top right)

2. **Add Chief Complaints:**
   - Type symptoms in "Chief Complaint" box
   - Example: "Chest pain, breathlessness"

3. **Record Diagnosis:**
   - Type in "Diagnosis" field
   - Example: "Angina pectoris"

4. **Add Medications:**
   - Click "Add Medicine" button
   - Start typing drug name (auto-suggests)
   - Select from dropdown
   - Choose:
     - Dosage (e.g., "5mg")
     - Frequency (e.g., "Twice daily")
     - Duration (e.g., "30 days")
     - Instructions (e.g., "After food")
   - Click "Add"
   - Repeat for all medicines

5. **Add Investigations (if needed):**
   - Click "Add Investigation"
   - Type test name (e.g., "ECG", "Lipid Profile")
   - Add special instructions if any

6. **General Instructions:**
   - Type advice for patient
   - Example: "Avoid oily food, light exercise"

7. **Save & Print:**
   - Click "Save Prescription"
   - Click "Print" to print
   - Prescription is automatically saved

**Practice Exercise:**
Create a sample prescription with:
- Chief Complaint: "Fever, cough"
- Diagnosis: "Upper respiratory tract infection"
- Medicines:
  - Paracetamol 500mg - Thrice daily - 5 days - After food
  - Azithromycin 500mg - Once daily - 3 days - Before food
- Investigation: Complete Blood Count
- Instructions: "Rest, drink warm fluids"

## 👩‍⚕️ Nurse Training (20 minutes)

### Module 1: Recording Vitals (15 minutes)

**When to record:**
- When patient arrives for consultation
- Before they see the doctor
- During ward rounds

**How to record:**

1. **Find Patient:**
   - Search by name or UHID
   - Click patient name

2. **Record Vitals:**
   - Click "Record Vitals" button
   - Fill in the form:
     - **Blood Pressure:**
       - Systolic (e.g., 120)
       - Diastolic (e.g., 80)
     - **Pulse:** beats per minute (e.g., 72)
     - **Temperature:** in °F (e.g., 98.6)
     - **SpO2:** oxygen saturation % (e.g., 98)
     - **Weight:** in kg (e.g., 65)
     - **Height:** in cm (e.g., 165)
   - BMI calculates automatically
   - Add notes if any (optional)
   - Click "Save Vitals"

3. **View Vital Trends:**
   - System shows graphs
   - Red/yellow warnings for abnormal values
   - Compare with previous readings

**Practice:**
Record sample vitals:
- BP: 130/85
- Pulse: 80
- Temp: 99.2°F
- SpO2: 97%
- Weight: 70 kg
- Height: 170 cm

## 🏥 Reception Training (15 minutes)

### Module 1: Registering New Patients (10 minutes)

**When a new patient arrives:**

1. **Click "Patients" → "Add New Patient"**

2. **Fill Patient Details:**
   - **Name:** Full name as per ID
   - **Age:** In years
   - **Gender:** Male/Female/Other
   - **Phone:** 10-digit mobile number
   - **Address:** Complete address
   - **UHID:** System auto-generates (or enter if from old system)
   - **Email:** Optional
   - **Emergency Contact:** Name and phone
   - **Blood Group:** If known

3. **Save:**
   - Click "Add Patient"
   - Patient added to database
   - UHID is shown - note this down
   - Give UHID to patient for future visits

**Practice:**
Register a test patient with sample data.

---

### Module 2: Scheduling Appointments (5 minutes)

**How to book:**

1. **Click "Appointments" in sidebar**

2. **Click "New Appointment":**
   - **Select Patient:**
     - Search by name/phone/UHID
     - Or click "Add New" for walk-in
   - **Select Doctor:** Choose from dropdown
   - **Date:** Click calendar
   - **Time:** Select time slot
   - **Type:**
     - Consultation
     - Follow-up
     - Investigation
   - **Notes:** Any special instructions
   - Click "Book Appointment"

3. **View Today's Appointments:**
   - See all appointments on dashboard
   - Mark as "Completed" when patient comes
   - Mark as "Cancelled" if patient doesn't show up

**Practice:**
Book a test appointment for tomorrow.

## 🔬 Lab Technician Training (15 minutes)

### Module 1: Uploading Lab Reports (10 minutes)

**When to upload:**
- After completing investigations
- When receiving reports from external labs

**How to upload:**

1. **Click "Lab Reports" in sidebar**

2. **Click "Upload New Report":**
   - **Select Patient:** Search and choose
   - **Report Type:**
     - Blood Test
     - Urine Test
     - ECG
     - X-Ray
     - Scan (CT/MRI/USG)
     - Other
   - **Test Name:** E.g., "Complete Blood Count"
   - **Test Date:** When test was done
   - **Upload File:** Click to select PDF/image
   - **Add Values Manually (optional):**
     - For blood tests, you can enter values
     - Example: Hemoglobin: 12.5 g/dL
     - System will auto-detect abnormal values
   - **Doctor's Notes:** Any observations
   - Click "Upload Report"

3. **AI Analysis:**
   - System automatically analyzes values
   - Highlights abnormal results in red/yellow
   - Provides reference ranges
   - Alerts doctor of critical values

**Practice:**
Upload a sample lab report PDF.

---

### Module 2: Viewing Lab History (5 minutes)

**How to view:**
1. Search for patient
2. Click "Lab Reports" tab
3. See all reports in timeline
4. Click any report to view/download

## 🛠️ Troubleshooting

### Common Issues and Solutions

#### "Patient not found" error
**Solution:**
1. Clear browser cache (Ctrl+Shift+Delete)
2. Hard reload (Ctrl+Shift+R)
3. Try searching by phone number instead of name
4. Contact IT support if problem persists

#### Cannot connect to server
**Solution:**
1. Check WiFi connection
2. Verify server IP address in URL
3. Ask IT: Is server running?
4. Try from another device

#### App is slow
**Solution:**
1. Close other browser tabs
2. Clear browser cache
3. Restart browser
4. Restart device if needed
5. Check internet connection

#### Forgot password
**Solution:**
1. Contact admin user
2. Admin can reset password from User Management
3. Admin: Settings → User Management → Reset Password

#### Prescription not printing
**Solution:**
1. Check printer is on and connected
2. Check printer has paper
3. Try Print Preview first
4. Try downloading as PDF instead

#### Data not syncing
**Solution:**
1. Check internet connection
2. Look at sync status in top-right corner
3. Click "Sync" button manually
4. Wait and retry after 1 minute

## ❓ Frequently Asked Questions

### General

**Q: Does NexaCare Pro work without internet?**
A: Yes! The app is **offline-first**. All data is stored on your device. Internet is only needed for syncing between devices.

**Q: Is my data safe?**
A: Yes! The app automatically backs up every hour. You can also create manual backups anytime from Backup & Restore page.

**Q: Can I access from home?**
A: Only if connected to hospital network. For security, access is restricted to hospital WiFi.

**Q: How many users can use at once?**
A: Up to 5 concurrent users (as per license).

---

### For Doctors

**Q: Can I edit an old prescription?**
A: No, prescriptions are locked after saving. You can create a new prescription with modifications.

**Q: How do I see patient's vital trends?**
A: Open patient → Vitals tab → See graphs and history.

**Q: Can I search by symptoms?**
A: Currently no. Search by patient name, UHID, or phone number.

**Q: Are prescriptions automatically saved?**
A: Yes, as soon as you click "Save Prescription".

**Q: Can I delete a wrong prescription?**
A: Contact admin. Only admin can delete records for safety.

---

### For Nurses

**Q: What if vitals are abnormal?**
A: System will show red/yellow warnings. Inform doctor immediately.

**Q: Can I edit vitals after saving?**
A: No. Record new vitals if correction needed. Old records are preserved.

**Q: Do I need internet to record vitals?**
A: No! Works completely offline.

---

### For Reception

**Q: Can two patients have same name?**
A: Yes. System uses UHID (unique ID) to distinguish.

**Q: What if patient forgets UHID?**
A: Search by phone number or name.

**Q: Can I cancel an appointment?**
A: Yes. Go to Appointments → Find appointment → Mark as Cancelled.

**Q: How to reschedule appointment?**
A: Cancel old appointment and create new one.

---

### For Lab Technicians

**Q: What file formats are supported?**
A: PDF, JPG, PNG for reports.

**Q: What if I upload wrong report?**
A: Contact admin to delete. You can upload corrected version.

**Q: Can I enter values manually without PDF?**
A: Yes! Use the manual entry fields in upload form.

**Q: Does AI work for all tests?**
A: Currently optimized for common blood tests. Expanding to more tests soon.

## 🎓 Best Practices

### For All Users:

1. **Always save your work** - Click Save before closing
2. **Logout when done** - Click logout button (top-right)
3. **Check sync status** - Look for green checkmark
4. **Report issues immediately** - Don't wait
5. **Take regular backups** - Admins: Daily backup recommended

### For Doctors:

1. **Review lab reports carefully** - AI suggestions are guidance, not diagnosis
2. **Double-check prescriptions** - Before printing
3. **Use standard abbreviations** - For better clarity
4. **Add clear instructions** - Helps pharmacist and patient

### For Nurses:

1. **Record vitals before consultation** - Saves doctor's time
2. **Use correct units** - BP in mmHg, Temp in °F, etc.
3. **Note abnormal values** - Alert doctor immediately
4. **Recheck if unsure** - Better to verify than record wrong value

### For Reception:

1. **Verify patient details** - Double-check phone number
2. **Note UHID clearly** - Give to patient
3. **Confirm appointments** - Call patient day before
4. **Keep schedule updated** - Mark completed/cancelled promptly

### For Lab Technicians:

1. **Upload reports same day** - Don't delay
2. **Enter values accurately** - AI depends on correct data
3. **Attach all pages** - Don't miss any page of report
4. **Verify patient match** - Ensure correct patient selected
